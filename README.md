
# Nigerian House Price Prediction Using Machine Learning

## Project Description

This project aims to develop a machine learning system that
estimates residential property prices in Nigeria using housing
features such as location, property type, bedrooms, bathrooms,
land size, age, and condition.

The application is being developed with Python, Pandas,
Scikit-learn, and Streamlit.

## Project Objectives

1. Collect and prepare suitable Nigerian housing data.
2. Explore housing characteristics and price distributions.
3. Train regression models to estimate house prices.
4. Evaluate models using MAE, RMSE, and R-squared.
5. Build a user-friendly prediction interface.
6. Document the methodology and experimental results.

## Development Status

Stage 1: Project setup, synthetic dataset generation,
data inspection, and initial Streamlit interface.

## Important Dataset Notice

The initial CSV contains synthetic demonstration records.
Its prices are generated by an invented formula and do not
represent actual Nigerian real estate market prices.

Reliable model training and real-world evaluation require
a suitable real-world dataset.

## Technologies

- Python

- Scikit-learn
- Matplotlib
- Streamlit

## How to Run

Activate the project's virtual environment, install the
requirements, generate the demonstration dataset, and run:

    python scripts/create_sample_data.py
    streamlit run app.py
